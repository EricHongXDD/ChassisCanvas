# 架构说明

CaseScreen 只有一条正式音乐同步链路：Windows 主机读取 QQ 音乐或网易云音乐当前播放对象的原生歌曲 ID，在同一平台取得歌词并维护播放时间轴，再向 USB 副屏发送小型状态包。系统不采集麦克风、不录音、不做声纹或标题识歌，也不要求额外桥接设备或辅助程序。

## 总体架构

```text
QQ 音乐 / 网易云音乐
        │
        ├─ Windows 媒体会话：标题、歌手、专辑、时长、播放状态和位置
        └─ 主机内置只读适配器：平台原生歌曲 ID
                         │
                         ├─ 同平台歌词接口与主机缓存
                         └─ 主机歌词时间轴
                                  │
                                  └─ 双行/时间戳/播放状态 + LV；启用进度轨时附 0..10000 细进度整数
                                                   │
                                                   └─ USB 小包 → 微雪驻留控件

Windows 硬件遥测 ----------------------------------------> 动态图层状态
Windows 默认播放端点 WASAPI loopback → FFT 频带 ----------> 动态图层状态
动态图层状态 + FFmpeg 视频帧 → Windows 合成 → 圆形裁切/方向补偿 → JPEG → 酷冷
可视化主题 → 原生控件编译 + 静态资源内嵌 → .Theme --------> 微雪 TF
```

图片、视频、字体和原生控件首次应用或内容变化时才上传到微雪 TF。日常播放不会重复传送这些资源，也不会传送完整歌词、歌曲 ID、连续播放位置、Cookie 或音频。

## 设备能力矩阵

| 品牌 | USB 标识 | 传输模式 | 资源驻留 | 动态歌词方式 |
|---|---|---|---|---|
| 微雪 7/8.8 英寸 | `1D6B:0104` | CDC ACM 串口命令 | 整套 `.Theme` 驻留 TF，按大小与 CRC 复用 | Windows 发送事件型歌词小包；有频谱时细进度合并进约 9～10 Hz 频谱包，无频谱时最高 20 Hz |
| 酷冷至尊 | `2516:0222` | HID interface 0 / 1024 字节报告 | 图片/MP4 五槽位；SHA-256 指纹去重 | 动态主题切换实时模式，由 Windows 合成完整 JPEG 帧 |

微雪 7 英寸已有握手、分辨率识别、主题编译、主题清单容量和 CRC 去重验证。酷冷至尊实时帧、Offline Mode 和模式恢复有既往真机记录；该记录不覆盖圆形几何、磁吸安装方向或本次方向校准链路。不同型号及不同验收范围的结论都不会互相外推。

## 酷冷显示几何与设备方向

酷冷至尊冷龙影二代使用 480×480 正方形像素缓冲区，实际可见 LCD 是其内接圆。尖角朝下的六边形表示磁吸外壳轮廓和逻辑正向，不是需要保留内容的六边形像素区域。因此编辑器继续使用 480×480 坐标，预览以圆形裁切显示有效内容，并在外侧画出尖角朝下的六边形安装参考。

磁吸模块转位属于设备安装状态，而不是主题内容。方向数据只保存在对应设备配置的 `display_rotation`、`orientation_calibrated` 和 `orientation_profile` 字段中，不进入主题 JSON。一个主题可在不同安装方向的酷冷设备上复用；导入、导出或切换主题不会覆盖方向。

校准测试图绕过已保存补偿，以原始像素方向显示普通钟面的 1～12，`6` 是原始逻辑下方。用户选择当前物理下方尖角旁的数字后，服务把它换算为 30° 步进的设备补偿并重新应用当前主题。测试图通过实时 JPEG 临时显示，不执行离线槽位的删除、传输或提交。测试模式由服务按设备保存在内存中，不写入主题或配置；运行中不会倒计时恢复。确认、取消、用户切换目标或完全退出才恢复当前主题，USB 重连则重发测试图。

同一个设备补偿位于主题渲染之后、设备传输之前：

```text
主题逻辑画布
  ├─ 动态主题：Windows 合成帧 → 圆形裁切 + 方向补偿 → JPEG 编码 → 实时 HID
  ├─ 静态主题：Windows 离线合成 → 圆形裁切 + 方向补偿 → JPG → Offline Mode 槽位
  └─ 视频背景：原 MP4 → FFmpeg 同角度转换 → MP4 → Offline Mode 槽位
```

实时 JPEG 的编码缓存键包含补偿角，避免同分辨率但安装方向不同的设备错误复用帧。离线 JPG 和 MP4 也以补偿后的媒体参与指纹与缓存；原始主题及其本地素材不被改写。该架构已有自动化映射、持久化、API 和编码前变换测试，但仍须按 [Windows 正式版验证](windows-verification.md) 完成方向专项真机验收后才能记录为实机通过。

## 平台身份

准确歌词身份由 `source + track_id` 组成：QQ 音乐使用 `songmid`，网易云音乐使用规范十进制歌曲 ID。

- QQ 的 Windows 媒体会话提供元数据和时间轴，主机内置只读适配器取得
  数值 songId，再按该 ID 获取单曲详情并严格核对后换成 `songmid`。
- 网易云内置只读适配器直接取得当前十进制 ID、播放/暂停、位置和时长，
  再只按同一 ID 从有界 `playingList` 快照取得元数据；可用 Windows 媒体
  会话作为额外交叉证据，不作为硬依赖。
- 任一证据缺失、越界、发生切歌竞态或彼此不一致时立即失败关闭，不按标题搜索或相似度猜测 ID。
- 平台登录态只用于用户主动选择的平台，并只继承该账号已有的会员和地区权益；登录不会获得额外 VIP 权益。

适配器只申请 Windows 进程查询与只读内存权限，不写播放器内存、不注入 DLL、不开放调试端口，也不启动外部程序。

## 歌词小包

微雪运行期复用原厂 `CommandSystemData`。歌词状态事件只发送以下六个键：

| 键 | 含义 |
|---|---|
| `CaseScreen_LyricsCurrent` | 当前句文本 |
| `CaseScreen_LyricsNext` | 下一句文本 |
| `CaseScreen_LyricsCurrentAtMs` | 当前句起始时间，毫秒 |
| `CaseScreen_LyricsNextAtMs` | 下一句起始时间，毫秒 |
| `CaseScreen_LyricsPlaying` | 是否正在播放 |
| `LV` | `0` 隐藏整个歌词层，`1` 显示；暂停且有当前句时仍为 `1` |

当当前微雪主题启用了可见的歌词进度轨时，新版 Theme 绑定
短键 `LFP`，值为当前句的 `0..10000` 整数细进度；
`CaseScreen_LyricsProgress` 的 `0..100` 整数仅用于兼容旧 Theme。频谱可见时，
`LFP` 合并进约 9～10 Hz 的完整频谱 `QStringMap`；频谱不可见时才独立发送，最高 20 Hz，且按可见像素去重。旧键不并入频谱，只在跨整百分比或状态事件时单独发送。播放器暂停后补发最终状态，随后不再周期发送。
极简样式或关闭进度轨时不绑定也不发送该键。

当前句和下一句各自最多 256 个 Unicode 字符。设备 ACK 后才记录最近载荷；相同且已确认的载荷不会重复发送。断线重连或重新加载主题后补发当前状态。

取词中、无歌词或当前句尚未出现时会通过显式清空包发送 `LV=0`、空双行、空时间戳、`playing=false` 和新旧零进度；面板、边框、样式线与进度底轨都由该键动态隐藏。暂停不会隐藏：主机保留当前/下一句、`LV=1` 和冻结进度。纯文本歌词也保持 `LV=1`，只显示固定的不可滚动说明。

歌词主时钟在 Windows 本地运行：

```text
播放：播放器锚点 + 主机经过时间 → 换行时发送基础事件；有频谱时细进度随约 9～10 Hz 频谱包发送，无频谱时最高 20 Hz
暂停：锁定当前位置 → 发送一次 playing=false 和最终进度，此后不推进、不轮询 USB
恢复：读取新锚点 → 发送一次 playing=true，并重新安排下一句截止时间
拖动：采用新位置 → 立即选择当前句并发送校正包
切歌：清空旧歌词 → 按新原生 ID 取词并发送新状态
```

有 LRC 时间轴时歌词滚动；只有纯文本时显示“该首歌的歌词暂不支持滚动”，不会伪造时间戳。

## 系统回放频谱

频谱输入来自 Windows 默认 Console 播放端点的 WASAPI shared-mode loopback。它复制扬声器或耳机即将播放的系统混音，不打开副屏或电脑麦克风，也不会改变主机声音输出设备。

主机把系统混音降为单声道，以 4096 点 Hann 窗和对数频带执行 FFT，分析上限 30 FPS。低于阈值的底噪按静音处理；停止播放时频带回到零，不生成假波峰。

微雪只接收量化后的 0–100 整数频带，相同载荷去重，串口忙时丢弃过期实时帧而不排队。酷冷至尊没有对应驻留动态键接口，频谱进入 Windows 合成画面；两类副屏都不会收到原始 PCM 或 FFT 复数。

## 微雪资源驻留

背景图片、背景视频和原生控件构成内容指纹命名的 `.Theme`。首次应用或内容变化时由 Windows 上传；连接、重启或重复应用时读取屏内清单，大小和 CRC 一致便直接激活。

静态图片编码为短循环背景；真实视频保留输入时长。内嵌 MP4 受 `.Theme` 24 位长度字段限制，单个资源上限为 16,777,215 字节。扩容 TF 镜像增加可用存储空间，不改变 USB 协议、内核驱动或播放器能力。

## 其他运行时策略

- 微雪模板库按设备分别保存编译清单和驻留记录。本机删除模板记录不会直接删除 TF 文件，避免误删屏内资源。
- V2.04 固件把 `bytesTotal` 和 `bytesAvailable` 放在 `command 3` 主题清单中；容量字段缺失时才回退尝试 `command 10`。
- 酷冷至尊纯背景可留在 Offline Mode；包含动态歌词、频谱或遥测时切换实时 JPEG。设备方向在两种模式之前统一补偿，主题 JSON 不保存安装角度。当前协议没有证据支持在离线槽位背景上用小键值包叠加控件。
- 两类设备传输失败后进入未连接状态并重试。微雪重连可复用已经驻留的资源。

## 安全边界

- 只实现显示、主题、亮度和方向等显示相关能力；不实现固件升级、引导区写入、水泵或风扇控制。
- 未确认握手、帧结构和 ACK 时禁止发送画面；酷冷至尊自动测试不覆盖离线槽位写入，方向测试图也不得借校准之名写入槽位。
- Windows 控制服务只监听本机回环地址，修改请求使用进程启动时生成的随机令牌。
- 不采集麦克风，不上传音频，不按标题猜 QQ/网易云原生 ID，不扩大用户已有平台权益。
- 平台登录态和歌词缓存只保存在 Windows 主机，不写入 Theme，也不进入副屏小包或诊断报告。
