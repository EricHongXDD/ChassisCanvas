# Windows 正式版架构

## 发布边界

CaseScreen 正式版是 Windows 主机程序。它只构建并发布
`CaseScreen.exe` 和 `CaseScreenDesktop.exe`。歌曲状态、同平台取词、
登录态加密、歌词计时和系统输出频谱都由当前电脑完成；副屏只接收 USB
显示数据。用户只需原有音乐客户端和 USB 副屏，无需购买、连接或安装
任何额外设备、服务或辅助程序。

正式运行边界如下：

- 音频频谱只读取 Windows 默认播放端点的最终混音，不打开录音或输入端点；
- 副屏不需要 Wi-Fi、互联网、平台账号或登录态；
- 平台会话只保存在当前 Windows 用户的加密存储中；
- GPU 设置只使用当前用户的 Windows 逐程序调度首选项，不安装驱动、不改全局显卡设置；
- 设备传输仅使用已实现的 CDC ACM 或 HID 协议。
- 关屏只发送设备协议中的亮度 `0`，不宣称或模拟 USB 断电；恢复亮度由对应驱动给出。

## 正式数据流

```text
QQ 音乐 / 网易云音乐 Windows 客户端
  -> QQ：GSMTC 播放状态、位置和媒体信息
     + 主进程有界只读内存取得并交叉核对原生 ID
  -> 网易云：主进程有界只读内存取得原生 ID、状态和时间轴
     + playingList 只按该 ID 取得元数据；可用 GSMTC 仅作额外交叉
  -> 主机使用同平台登录态取得并缓存歌词
  -> 主机本地定时选择当前句与下一句
  -> 换行、暂停、恢复、拖动或切歌时发 USB 紧凑歌词状态小包（含 LV）
  -> 启用微雪进度轨时更新短整数键 LFP
     （有频谱时并入约 9～10 Hz 完整频谱包；无频谱时独立发送且最高 20 Hz）
  -> 微雪 TF 驻留 Theme 控件

Windows 默认 Console 播放端点
  -> WASAPI shared-mode loopback
  -> 主机 FFT + 量化频带
  -> USB 小型键值包（微雪）/变化后 JPEG 帧（酷冷）
```

WASAPI 回环复制默认扬声器或耳机的最终混音。它使用共享模式，
不打开录音或输入端点，不创建虚拟声卡，不改写播放器输出设备。

歌词的字体、字号、颜色、描边、阴影、柔光、面板、高亮与进度轨只改变
驻留 Theme 或主机 JPEG 的显示样式；频谱的形状、方向、粗细、间距、内径、
渐变、灵敏度、平滑度、静音门限、峰谷对比和邻频分离只改变真实 FFT 频带的
量化与布局。歌词状态事件由原有五个双行/时间戳/播放字段加一个 `LV` 短标量组成；只有微雪主题启用进度轨时，才会
更新一个 0～10000 的短整数键 `LFP`。频谱可见时该键并入约 9～10 Hz 的完整频谱 `QStringMap`；
没有频谱时才独立发送且最高 20 Hz，并按原生轨道可见步进去重。整份歌词、连续播放位置和 PCM 音频不会进入
日常设备包。微雪主题在应用时还会为每组不同的音频变换分配确定性短键；
相同变换的条状与环状图层共享频带，从而让完整 48 频带保持接近 10 FPS，
而不增加音频采集或传输 PCM。

## 两类设备的差异

| 设备 | 静态资源 | 遥测、频谱和歌词 |
|---|---|---|
| 微雪 7/8.8 英寸 | `.Theme` 首次或内容变化时写入 TF | Windows 经 CDC ACM 发 `QStringMap` 小包 |
| 酷冷至尊冷龙影二代 | 背景图/MP4 可进入 Offline Mode 槽位 | 动态主题由 Windows 合成 JPEG 并经 HID 发送 |

基础歌词事件包包含 `CaseScreen_LyricsCurrent`、`CaseScreen_LyricsNext`、
`CaseScreen_LyricsCurrentAtMs`、`CaseScreen_LyricsNextAtMs` 和
`CaseScreen_LyricsPlaying`，并增加 `LV` 表示整层是否可见。它不含连续播放位置、整份歌词、背景媒体、
平台 ID、Cookie 或 PCM。微雪 Theme 绑定前两个文本键；启用进度轨时新版主题还绑定
`LFP` 的 0～10000 整数，`CaseScreen_LyricsProgress` 的
0～100 整数作为旧 Theme 兼容键，后三个时间/播放元数据继续作为稳定契约。
暂停会冻结主机选句计时器并发送一次 `Playing=false`；若启用了进度轨，同一
暂停事件还会携带最终新旧进度整数。恢复、拖动和切歌也会
立即补发状态。进度轨播放期间，频谱可见时把细整数合并进约 9～10 Hz 的完整频谱包；
无频谱时才独立发送且最高 20 Hz，可见像素不变时跳过。旧键不进入频谱包，只在跨整百分比或状态事件时单独发送；暂停后不再周期发送；
不会按帧传送连续播放位置。
已确认 ACK 的相同数据会去重，断线重连后只补发当前状态。

等待取词、无歌词或当前句尚未出现时发送显式清空包：`LV=0`、空双行、空时间戳、`Playing=false` 和新旧进度归零。新版驻留 Theme 会据此同时隐藏歌词文字、面板、边框、样式装饰与进度底轨，不显示等待占位。暂停且已有当前句时保持 `LV=1` 与原双行，只冻结时间轴；纯文本歌词也保持 `LV=1` 并显示固定说明。
升级前已经准备的微雪歌词 Theme 不具备该可见性契约。模板库和轮播在激活时自动重编译旧产物；普通活动主题首次升级后需在编辑器重新应用一次。缺少源素材时失败关闭并提示重新保存，不能静默写回旧 Theme。
重连采用 2/4/8/16/30 秒有界指数退避，30 秒封顶，连接成功后复位；恢复时
重新应用待生效或当前主题与最新状态，已驻留资源不重复上传，过期实时帧不排队。
用户明确设置的关屏意图会写入配置，并在断线重连、完全退出或系统重启后保留：
主题恢复完成后再次发送亮度 `0`。关屏中的主机合成目标不渲染、不编码也不发送 JPEG；恢复后立即补一帧
当前主题。工作台窗口的 `X` 仅隐藏到 Windows 系统托盘，“完全退出”才销毁
窗口并停止同目录托管的后台服务。

## 进程与凭据

- `CaseScreen.exe` 负责设备、遥测、WASAPI、播放器状态、主机取词和本机 API。
- QQ 原生 ID 后备适配器属于 `CaseScreen.exe` 本身，只对同用户的
  `QQMusic.exe` 申请 `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ`；不写内存、不加载进
  QQMusic、不安装 DLL，也不启动其他程序。只有 `QQMusic.dll`
  整体不超过 20 MiB 时才完整扫描；模块超限、分块读取失败、候选负缓存、
  多进程证据冲突、特征码、结构、媒体字段或时间轴不一致时立即整轮失败关闭，
  不接受模块前缀结果。该结构依据上游原始仓库
  3.1 发布版所标注的 QQ 音乐 20.43+，客户端更新后必须重新真机验收。
- 网易云原生 ID 适配器同样属于 `CaseScreen.exe` 本身，只对同用户的
  `cloudmusic.exe` 申请 `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ`。
  它对所加载的 `cloudmusic.dll` 做有界特征定位，并只读取当前歌曲 ID、
  位置、时长和播放状态；随后只按该精确 ID 从官方客户端本机 `playingList`
  的有界稳定快照取得曲名、全部歌手、专辑和时长，其他列表条目不参与候选。
  它不会写内存、注入 DLL、启动调试端口、读取 Cookie 或控制播放器。
  候选进程、特征、结构或同 ID 元数据不唯一，任一读取失败，或可用 GSMTC
  与原生证据不一致时立即失败关闭。客户端更新后必须重新真机验收，不能回退到
  `webdb`、窗口标题或标题搜索。
- `CaseScreenDesktop.exe` 是唯一桌面工作台实例。它自动启动同目录服务；同目录已有经版本与身份核验的同版手动 tray/headless 服务时，先结束它再转为桌面托管，使“完全退出”能同时清理后台。会话暂时无法核验时只报错并保留原进程，不会根据窗口已隐藏就当作旧版孤儿终止。
- “程序”页只为同目录的 `CaseScreen.exe` 和 `CaseScreenDesktop.exe` 写入当前
  用户 `HKCU\Software\Microsoft\DirectX\UserGpuPreferences` 中的首选项。
  下拉框提供“系统自动”和 Windows 实际枚举到的物理适配器名称；后端将具体
  适配器映射为注册表支持的调度类别。设置系统自动时只移除 `GpuPreference` 字段，
  保留同一注册表值内其他 DirectX 选项。所选适配器 ID 与名称同时写入配置，重开
  后仍可恢复选择。两个程序的写入是成组操作，后一个失败
  会回滚前一个。由于 Windows 以 EXE 绝对路径作为登记键，桌面入口会在创建
  Gio 图形资源和启动后台前，把配置中的已保存选择重放到当前发行目录；换目录后
  首次产生登记变化时会带一次性标记自重启，确保新进程从启动之初采用该提示，
  且不会形成重启循环。该值是 Windows 调度提示而非强制显卡绑定；在“程序”页
  重新保存后仍需退出并重新打开两个程序，已经创建的 Gio 或图形资源不会在进程内迁移。
- 设置 API 固定监听 `127.0.0.1`、`localhost` 或 `::1`，不暴露到局域网。
- 平台会话使用 AES-GCM 加密；会话密钥以 `CSPK2` 封装并由当前
  Windows 用户 DPAPI 保护。旧版 32 字节密钥会原子迁移，已有 AES-GCM
  会话数据无需重写。
- 平台登录态只保存在 Windows 用户配置目录，不复制到主题、TF、
  设备配置示例或发行 ZIP。打开官方登录页不会自动读取会话，仍需
  用户主动导出并在主机导入一次 `cookie.txt`。该文件只是导入载体；
  导入后主机会跨启动加密复用，直到平台过期、撤销或拒绝，无需每次启动
  重新导入。CaseScreen 不持续读取也不自动删除源文件。

歌词的精确 ID、暂停/恢复与小包规则见 [Windows 主机歌词同步](host-lyrics.md)；
发布验收见 [Windows 正式版验证](windows-verification.md)。
