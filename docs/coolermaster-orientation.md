# 酷冷至尊显示几何与方向校准

本文说明酷冷至尊冷龙影二代 LCD 的逻辑画布、磁吸外壳方向和 CaseScreen 的设备级补偿。这里记录的是功能契约与待执行验收方法，不代表该方向功能已经完成真机验收。

## 物理显示模型

- USB/HID 画面缓冲区和主题逻辑画布均为 480×480。
- 实际可见 LCD 是 480×480 正方形缓冲区中的圆形有效区；圆外像素不可作为可见内容使用。
- 尖角朝下的六边形是磁吸外壳轮廓及逻辑正向参考，不是六边形 LCD。编辑器应裁切为圆形，并在圆外显示六边形参考线。
- 磁吸模块可转位，导致同一像素缓冲区相对外壳的物理下方发生变化。该差异属于设备安装状态，不属于主题设计。

主题作者始终按“外壳尖角朝下”的 480×480 逻辑正向排版。圆边附近可能被面板裁掉，文字、数值和进度等关键信息应留在圆内安全区。

## 一次性设备校准

方向校准图不应用当前补偿，而是直接按原始像素方向临时发送。图中 1～12 按普通钟面每 30° 排列，`6` 位于原始逻辑下方，中央 `POINT DOWN` 箭头也指向原始下方。

用户操作流程：

1. 在工作台选择具体的酷冷至尊副屏，不选择“全部副屏”。
2. 先确保该屏已有一份可恢复的当前主题，再点击显示方向测试图。
3. 找到当前物理下方尖角旁边显示的数字。
4. 选择该数字并保存。如果物理下方尖角恰好与原始像素下方一致，选择 `6`，此时补偿为 0°。
5. 检查当前主题恢复且正向与物理下方一致。

标识与补偿的映射如下；正角度表示输出画面视觉上顺时针旋转：

| 物理下方标识 | 补偿角度 | 物理下方标识 | 补偿角度 |
|---:|---:|---:|---:|
| 1 | 210° | 7 | 30° |
| 2 | 240° | 8 | 60° |
| 3 | 270° | 9 | 90° |
| 4 | 300° | 10 | 120° |
| 5 | 330° | 11 | 150° |
| 6 | 0° | 12 | 180° |

30° 标识同时覆盖六边形外壳的 60° 磁吸位置和固件/面板可能出现的 90° 相对方向。用户只选择看到的数字，不需要推导或手工填写角度。

保存后的方向属于对应设备，写在 CaseScreen 设备配置中：

```json
{
  "id": "coolermaster-atmos-v2",
  "kind": "coolermaster",
  "display_rotation": 90,
  "orientation_calibrated": true,
  "orientation_profile": 1
}
```

这三个字段不得写入主题 JSON。主题中的图层旋转仍只表示设计者对单个图层的排版，不等于设备安装方向。导入、导出、复制或切换主题都不能覆盖设备校准；更换设备或重新改变磁吸位置时才需要重新校准。

## 三条输出路径使用同一补偿

方向处理位于逻辑主题之后、设备媒体传输之前：

| 输出路径 | 补偿位置 | 结果 |
|---|---|---|
| 动态实时画面 | 完成遥测、频谱、歌词和视频帧合成后，先做圆形裁切与设备旋转，再编码 JPEG | HID 接收已经校正的实时 JPEG |
| 离线静态画面 | 合成静态图层后，做相同圆形裁切与设备旋转，再编码 JPG | 槽位保存已经校正的 JPG |
| 离线视频背景 | 按同一设备角度使用 FFmpeg 转换 MP4；圆形可见边界由物理 LCD 保证 | 槽位保存已经校正的 MP4 |

实时编码缓存把方向角作为键的一部分，因此两台同为 480×480、但磁吸方向不同的设备不会错误共用 JPEG。离线 JPG/MP4 的补偿结果也分别参与媒体指纹与缓存；CaseScreen 不修改原始主题 JSON 或原始素材文件。非零角度的离线 MP4 需要可用的 `ffmpeg.exe`。

保存新方向后，服务会按新补偿重新应用该设备当前主题。动态主题重新建立实时帧链路；离线主题按新方向准备媒体并根据实际指纹决定是否需要更新槽位。若设备暂时断开，持久化方向在重连并重新应用主题时生效。

## 测试图的安全边界

- 测试图只通过实时 JPEG 临时显示，不调用 Offline Mode 的删除、上传或提交命令。
- 显示测试图前会暂停该设备的普通主机帧，避免主题帧立即覆盖标识。
- 点击保存会应用所选方向并恢复当前主题；点击取消只恢复当前主题，不改已保存方向。
- 用户不操作时测试图会一直显示，不再以 2 分钟或其他倒计时自动恢复。
- 保存或取消遇到 USB/素材处理失败时不会提前丢弃校准会话，工作台保留确认/取消入口；USB 重连后服务重发测试图。
- 用户明确切换到其他目标或完全退出软件时会恢复当前主题；退出恢复发生在关闭 USB 驱动之前。
- 没有可恢复的当前主题时会拒绝显示测试图，避免屏幕停在临时画面。
- 校准只接受一台已配置的酷冷至尊目标；不能对“全部副屏”或微雪设备执行。

测试图不写槽位并不表示“保存方向后永远不更新离线媒体”：保存会重新应用当前主题；如果当前主题使用离线 JPG/MP4，正确行为是按新方向生成新的媒体并走正常的指纹和槽位更新流程。二者必须在验收记录中区分。

## 真机验收记录要求

方向功能尚需在目标发行包和目标硬件上执行以下步骤，自动化测试不能替代：

1. 记录发行包版本与 SHA-256、设备 ID、磁吸安装位置、配置槽位和校准前槽位媒体指纹。
2. 检查工作台是圆形有效区加尖角朝下六边形参考，不得显示成六边形有效 LCD。
3. 显示测试图，拍摄 1～12、中央箭头和物理下方尖角；测试图的原始逻辑下方必须是 `6`，只有它与物理尖角对齐时尖角旁才应看到 `6`。
4. 不保存并等待至少 2 分钟，确认测试图持续显示；点击取消后才应立即恢复主题。
5. 对比上述两个过程前后的槽位媒体与指纹，确认测试图本身没有触发删除、上传或提交。
6. 改变磁吸位置，选择物理下方数字并保存。使用带明显上下方向标记的同一主题，分别检查动态实时 JPEG、离线 JPG 和离线 MP4。
7. 切换主题、重插 USB、完全退出并重启程序，确认设备方向仍保持；导出主题 JSON，确认其中没有三个设备方向字段。
8. 记录所选数字、计算补偿、三条媒体路径的照片、槽位未改写证据和重启结果。任一项缺失时不得写“方向真机验收通过”。

总体验收清单见 [Windows 正式版 1.0 验证](windows-verification.md)。
