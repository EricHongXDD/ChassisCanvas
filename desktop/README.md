# CaseScreen 纯 Go 桌面主题工作台

发行包可直接双击上一级目录的 `CaseScreenDesktop.exe`。它会自动启动或复用同目录的 `CaseScreen.exe` 服务，并打开 Gio 原生窗口。

桌面端不依赖 Python、PySide6 或额外运行时。左侧组件库点击添加组件，中间画布可拖动/缩放图层，右侧属性面板编辑位置、样式与数据绑定；背景图片/视频、本地 LRC 都在选中对应图层后通过文件选择器设置。歌词可调播放器式层次、字体、当前/下一句字号与颜色、描边、阴影、柔光、高亮和进度轨；条状/环状频谱可调样式、方向、频带数、间距、粗细、内径、渐变、灵敏度、平滑度、静音门限与峰谷差。顶部可选择目标副屏，也可导入主题 JSON 后继续可视化编辑并只应用到所选设备。

右侧新增“预设”页，提供遥测 4 种、条状频谱 7 种、环状频谱 6 种、歌词 4 种不同布局与配色。选中同类图层后点击预设会直接套用；未选中同类图层时，会在画布中心创建对应图层。预设仅修改外观，不改变遥测绑定和音频动态参数。

顶部设备区可对当前副屏或全部副屏执行“关屏/恢复”。关屏使用设备亮度 `0` 实现黑屏，并不切断 USB 电源；关屏意图会在断线、完全退出和系统重启后保留，关屏中的主机合成屏会暂停 JPEG 渲染和传输。点击窗口右上角 `X` 只隐藏到 Windows 系统托盘，托盘图标可重新打开工作台；只有托盘右键菜单中的“完全退出”会停止工作台及其托管服务。

右侧“程序”页提供“检测到的显卡”下拉框，首项为“系统自动”，其余选项直接显示 Windows 枚举到的物理显卡名称。保存会持久化所选适配器，并把它映射为 Windows 支持的逐程序调度类别后统一登记同目录的 `CaseScreen.exe` 与 `CaseScreenDesktop.exe`。该值是 Windows 调度提示，不保证强制固定到某块显卡；保存后需退出并重新打开两个程序。升级或移动发行目录时，桌面入口会在创建 Gio 图形资源和启动后台前，把已保存选择迁移到新目录的两个绝对 EXE 路径；若登记发生变化，会自动自重启一次后再打开窗口。

QQ 音乐和网易云音乐的受限歌词登录入口位于歌词图层属性。程序只打开平台官方页面并导入用户导出的 `cookie.txt` 会话，不保存账号或密码；登录态加密留在此 Windows 主机，不发送到副屏。歌曲状态、取词和歌词计时都由当前电脑完成，副屏只通过原有 USB 连接接收显示数据，无需额外设备、网络设置或辅助程序。
